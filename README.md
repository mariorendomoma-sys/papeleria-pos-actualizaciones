# Papelería POS — actualizaciones

Este repositorio **sólo contiene instaladores** de Papelería POS para Windows, publicados como *Releases*. El programa instalado los descarga de aquí para actualizarse solo al cerrar.

- No contiene código fuente, bases de datos, respaldos, contraseñas ni información del negocio.
- Cada versión publicada incluye el instalador (`.exe`), su `.blockmap` y `latest.yml`. El programa usa `latest.yml` para saber si hay una versión nueva y para verificar el instalador (SHA-512).
- Las versiones en borrador (*draft*) y las *pre-release* no se distribuyen: el programa las ignora.
